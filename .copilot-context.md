# GitHub Copilot Chat Configuration for SAP CF MCP Project

## Project Context
This workspace contains an SAP BTP Cloud Foundry MCP (Model Context Protocol) server with the following capabilities:

### 🔧 Available Tools
- **parse_mta**: Parse MTA (Multi-Target Application) descriptor files
- **get_access_token**: Get OAuth access tokens from XSUAA services
- **get_cf_resources**: Query Cloud Foundry APIs for resources

### 🚀 Quick Commands
Use these npm scripts directly in VS Code terminal:

```bash
# List all MTA files in workspace
npm run mcp:list

# Parse a specific MTA file
npm run mcp:parse ./path/to/mta.yaml

# Start MCP server
npm run mcp:server

# Interactive menu
npm run tools:menu
```
